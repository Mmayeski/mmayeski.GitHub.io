Add Article Analysis

Manual workflow for adding claim analysis to articles

How It Works

1. Analyze an article with Claude

Copy the article text and use the prompt template below. Claude will return a JSON object with claims and scores.

Prompt Template

Analyze this news article for source quality. For each major claim, rate it 1-10:

1-2: Rumor, speculation, anonymous sources
3-4: Single unnamed source, unverified claims
5-6: Named sources, but not independently verified
7-8: Multiple named sources, documented evidence
9-10: Official records, court documents, public data

Return JSON in this exact format:
{
  "claims": [
    {
      "text": "The specific claim from the article",
      "score": 7,
      "reasoning": "Brief explanation of the score"
    }
  ]
}

ARTICLE:
[Paste article text here]

2. Edit the claims data file

Open this file in your repo:

/data/claims.json

Add a new entry under "articles" with the article URL as the key:

{
  "articles": {
    "https://example.com/your-article-url": {
      "title": "Article Title",
      "source": "Source Name",
      "analyzed_at": "2026-02-03T12:00:00Z",
      "claims": [
        {
          "text": "The specific claim",
          "score": 7,
          "reasoning": "Why this score"
        }
      ],
      "avg_score": 7.0
    }
  }
}

3. Commit and push

After editing claims.json, commit and push to deploy:

git add data/claims.json
git commit -m "Add analysis for [article name]"
git push

The article will show the real scores on the next deploy.

Important Notes

URL matching: The article URL in claims.json must exactly match the URL from your news source.

Average score: Calculate it manually: sum of all scores / number of claims.

Sample articles: The current demo uses placeholder URLs like https://example.com/article/1. When you connect a real news feed, use those URLs.
